## 🎯 Two Labels - Choose Wisely

| 🔴 Protected B - Secure Meeting | 🟢 General - Regular Meeting |
|--------------------------------|------------------------------|
| **Use for classified/sensitive content** | **Use for casual/administrative** |
| Watermarks: ON 🔒 | Watermarks: OFF |
| External users: BLOCKED 🔒 | External users: ALLOWED ✏️ |
| Presenters: Organizer only 🔒 | Presenters: Everyone ✏️ |
| Recording: Controlled 🔒 | Recording: Flexible ✏️ |
| **DEFAULT - Auto-selected** | **Must change manually** |

---

## ⚡ Quick Decision Tree

```
Creating a meeting?
    ↓
Will you discuss ANY classified or sensitive info?
    ↓
┌─ YES → 🔴 Protected B - Secure Meeting
│         Keep the default!
│
└─ NO  → Is it purely social/admin?
          ↓
       ┌─ YES → 🟢 General - Regular Meeting
       │         Change the label
       │
       └─ UNSURE → 🔴 Protected B - Secure Meeting
                    When in doubt, be secure!
```

---

## ✅ ALWAYS Use Protected B For:

- ✅ Government contracts
- ✅ Technical specifications  
- ✅ Customer confidential data
- ✅ Pricing/proposals
- ✅ Engineering designs
- ✅ NDA-covered topics
- ✅ HR/personnel matters
- ✅ Financial information
- ✅ Any meeting with government reps
- ✅ **WHEN IN DOUBT!**

---

## ✅ Use General For:

- ✅ Team stand-ups (non-sensitive)
- ✅ Social gatherings
- ✅ Training (non-classified)
- ✅ Birthday parties
- ✅ Routine admin meetings
- ✅ Public presentations

---

## 📝 How to Create a Secure Meeting

**Protected B (Default - Keep It!):**
```
1. Calendar → New meeting
2. Sensitivity: "Protected B - Secure Meeting" ✓
   (Already selected by default!)
3. Add attendees
4. Send
```

**General (Change from Default):**
```
1. Calendar → New meeting
2. Click: Sensitivity dropdown ▼
3. Select: "General - Regular Meeting"
4. Add attendees
5. Send
```

## ⚠️ Common Mistakes - DON'T DO THIS!

| ❌ DON'T | ✅ DO INSTEAD |
|----------|---------------|
| Use General for contract talks | Use Protected B |
| Downgrade to General so external can join | Use proper secure channels |
| Ignore watermarks | Understand they're required |
| Think "quick call" = "not sensitive" | Evaluate content first |
| Forget to check label | Make it a habit! |

## 🆘 Troubleshooting

**Problem: Can't see Sensitivity option**
→ Wait 24-48 hours (labels just rolled out)
→ Sign out/in to Teams
→ Contact IT if still missing after 48 hours

**Problem: External person can't join Protected B**
→ This is BY DESIGN - protected B blocks external
→ Use General IF content is not sensitive
→ Or request guest account from IT

**Problem: Can't change label mid-meeting**
→ Cannot change once meeting starts
→ End meeting and create new one with correct label

**Problem: Can't share screen in Protected B**
→ Ask organizer to make you co-organizer
→ Or organizer shares on your behalf
