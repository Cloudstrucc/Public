## 🎓 Training Session Outline

**Duration:** 60 minutes

**Agenda:**

**Introduction (5 minutes)**
- Why we're implementing this
- Security context
- Compliance requirements

**The Two Labels (10 minutes)**
- Protected B explained
- General explained
- Visual comparison
- When to use each

**Live Demo (15 minutes)**
- Create Protected B meeting
- Show watermarks
- Show locked settings
- Create General meeting
- Show flexible settings
- Switch between labels

**Decision Making (10 minutes)**
- Walk through decision tree
- Review common scenarios
- Practice with examples
- Answer "when in doubt" questions

**Hands-On Practice (15 minutes)**
- Attendees create test meetings
- Try both label types
- Experience the differences
- Ask questions

**Q&A (5 minutes)**
- Open floor for questions
- Address concerns
- Clarify confusion
- Provide resources
